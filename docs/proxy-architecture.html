Native preserves selected protocol content
JSON bodies preserve response fields, citations and signatures. SSE preserves data and named events, including unknown event types. The parser and writer reframe the wire: comments, id and retry are not preserved by the native strategies.

        
Outbound payloads are normalized
Copilot rewrites model aliases, filters beta headers, normalizes thinking and tool options. Custom Anthropic lowercases the model, drops context_management, keeps only output_config.effort and omits the incoming anthropic-beta header. These paths are not byte-transparent request relays.

Can the existing UT guarantee translation?
No. Execution coverage does not test all event orderings, capability combinations or cancellation. This review reproduced failures in modules with 100% line coverage.

        
Scope and exclusions
  • Proxy: src/**/*.ts, excluding declarations, index.ts, migration.ts, paths.ts and upstream/interface.ts.
  • Dashboard: its declared non-View scope; UI wrappers and other configured exclusions remain unchanged.
  • Scripts: scripts/lib/**/*.ts, excluding their tests.
  • Live E2E, real provider credentials, socket-level cancellation and deployed services were not exercised.

        
Passing contracts added
  • Anthropic ↔ Chat text, usage and two-turn tool IDs / escaped JSON.
  • JSON / SSE stop-reason parity and sequential tool block lifecycles.
  • Native JSON unknown fields, citations, signatures and prompt-cache metadata.
  • Native SSE opaque signatures and future event types.
  • Chat ↔ Responses call_id integrity over two turns.
  • Explicit unsupported-route 400 responses without upstream calls.
  • UTF-8 parsing across every two-chunk byte split for LF and CR line endings.

        
Performance evidence and limits
  • R06 measures wasted work deterministically: all 20 waiting chunks are adapted after cancellation. It does not use a timing threshold.
  • Server-tool interception bypasses the ordinary Runner and buffers full responses before SSE replay, delaying the first output and retaining the buffered content.
  • The existing test/perf/sse.bench.test.ts benchmarks parseSSELine and parseSSEStream, often with one full input buffer. It does not measure the production events(response) parser.
  • Large incomplete SSE lines are repeatedly rescanned: a static risk, not a measured latency or memory result.

        
Remaining protocol limits
Malformed/truncated tool arguments currently throw; fallback semantics need an explicit contract. Model-specific sampling restrictions and vendor-specific split id/name fields were inspected but not certified. No live provider or socket-level cancellation claim is made.
